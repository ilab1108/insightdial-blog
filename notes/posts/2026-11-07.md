# LinkedIn post - 2026-11-07

Affiliate payout disputes rarely start with the money. They start with two different counts of the same calls.

If you pay affiliates for calls, a few habits make payouts far less painful:

- Give every affiliate their own tracking number, so each call is attributed the moment it arrives.
- Set the payout rate per affiliate in the system, not in an email thread.
- Write down what makes a call payable: minimum length, location, repeat callers, blocked numbers.
- Let affiliates see their own calls and earnings, so they don't have to ask you for a number.
- Settle buyer disputes from the call record before you pay out, not after.

None of this removes disagreements. It moves them to the start of the relationship, where they're cheap to settle, instead of month-end, where they aren't.
